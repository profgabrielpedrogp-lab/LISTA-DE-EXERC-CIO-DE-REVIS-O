# Lista de Exercícios — Proposições e Conectivos

Página HTML estática para a lista de exercícios de Raciocínio Lógico do Lidera Concursos, com gabarito comentado e opção de impressão.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

Não são necessárias bibliotecas, instalações ou arquivos adicionais: a página funciona diretamente no navegador.
